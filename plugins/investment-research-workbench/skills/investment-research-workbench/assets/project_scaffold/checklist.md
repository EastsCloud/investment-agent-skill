# Investment research checklist / 投资研究清单

Generic starter questions, not adopted user principles / 通用问题，不代表用户已经认同的原则。

## Company fundamentals / 公司基本面

- [ ] Core business, revenue and profit sources / 主营业务、收入来源、利润来源
- [ ] Customers, cost structure, business model, value-chain position / 客户、成本结构、商业模式、产业链位置
- [ ] Cyclical, growth, platform or resource characteristics / 周期、成长、平台、资源属性

## Industry / 行业

- [ ] Industry stage, supply, demand, key prices, competition / 行业阶段、供给、需求、核心价格、竞争格局
- [ ] Distinguish industry beta from company alpha / 区分行业 beta 和公司 alpha

## Financials and valuation / 财务与估值

- [ ] Revenue drivers, gross-margin changes, earnings quality / 收入驱动、毛利率变化、利润质量
- [ ] Cash flow, balance sheet, valuation method, implied expectations / 现金流、资产负债、估值方法、市场隐含预期
- [ ] Comparable sources, dates, units and accounting definitions / 来源、日期、单位和会计口径是否可比

## Buying / 买入

- [ ] Why now, core thesis, triggers, evidence to verify / 为什么现在研究、核心 thesis、触发条件、待验证数据

## Selling / 卖出

- [ ] Thesis invalidation, excessive valuation, cycle peak, deterioration / 证伪条件、估值过高、周期到顶、基本面恶化
- [ ] Separate short-term volatility from a mistaken thesis / 区分短期波动与判断错误

## Bear case / 反方观点

- [ ] Strongest counterargument / 最强反方观点
- [ ] Why might the market be right? / 市场为什么可能是对的
- [ ] What evidence would prove the user wrong? / 什么数据证明用户错了

## Risks / 风险

- [ ] Industry, company, financial, valuation, policy / 行业、公司、财务、估值、政策
- [ ] Technology substitution, management, sentiment / 技术替代、管理层、市场情绪
