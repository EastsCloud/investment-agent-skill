# 投资研究 Checklist

通用 starter questions，不等于用户已经认同的投资原则。

## 公司基本面

- [ ] 主营业务、收入来源、利润来源
- [ ] 客户、成本结构、商业模式、产业链位置
- [ ] 周期 / 成长 / 平台 / 资源属性

## 行业

- [ ] 行业阶段、供给、需求、核心价格、竞争格局
- [ ] 行业 beta 与公司 alpha 分别是什么？

## 财务与估值

- [ ] 收入驱动、毛利率变化、利润质量
- [ ] 现金流、资产负债、合适估值方法、市场隐含预期
- [ ] 数据来源、日期、单位、会计口径是否可比？

## 买入

- [ ] 为什么现在研究、核心 thesis、触发条件、需要验证的数据

## 卖出

- [ ] thesis invalidation、估值过高、周期到顶、基本面恶化
- [ ] 短期波动与判断错误如何区分？

## Bear case

- [ ] 最强反方观点
- [ ] 市场为什么可能是对的？
- [ ] 哪些数据证明用户错了？

## 风险

- [ ] 行业、公司、财务、估值、政策
- [ ] 技术替代、管理层、市场情绪
